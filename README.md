## Overview

LateCompany is a Lethal Company mod that enables players to join an active lobby even after the game round has begun, eliminating the frustration of being locked out of a session when friends started without you. It handles late-join synchronization of quota state, collected loot, and player positions, integrating seamlessly with the BepInEx mod loader.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **LateCompany** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Mid-Game Join** | Join active Lethal Company lobbies without waiting for a new round |
| **State Sync** | Quota, loot, and player positions synchronize correctly on late join |
| **BepInEx Compat** | Standard BepInEx plugin with no additional dependencies required |
| **Host Control** | Host can configure whether late joining is permitted per lobby |
